How to mark a song

You are tagging stretches of the CD. The tab later supplies guitar, lead, bass and drums for those bars. Overlapping tags are stickers on the same bars, not two guitars.

Buttons

  • Intro — pads, swell, count-in
  • Build — rising into a drop
  • Riff — the main repeating guitar idea only
  • Hook — the bit you hum / unison chorus
  • Breakdown — half-time slam. Drums often change, guitar may not
  • Solo — lead / sweep / tap
  • Chill — clean / ambient space
  • Pulse — techno / synth clock, not a guitar chug
  • Outro — end figure

Best practice

  • Green-dot tracks only (flac + tab).
  • Same riff looping = one Riff box. Do not chop every repeat.
  • Guitar stays, drums go half-time = layer Riff + Breakdown on the same seconds.
  • New guitar idea = new box. New job for the same idea = extra layer.
  • Guess is a draft. If it marks Breakdown and it is not, change the dropdown in the table. Then Save.
  • Click the wave to seek. Drag the box to move. Drag an edge to resize.
  • Download JSON after each track as backup.

Do not

  • Label every song tonight. Ten to fifteen good ones beat sixty sloppy ones.
  • Trust Guess on GP7 files (unsupported version). Paint those by ear.
